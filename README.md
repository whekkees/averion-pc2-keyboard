# Averion OS - Мини-драйвер клавиатуры

Этот проект содержит низкоуровневый мини-драйвер PS/2 клавиатуры и модуль ввода-вывода (I/O) для операционной системы Averion OS. 

Код написан на языке Rust для архитектуры x86 без использования стандартной библиотеки (no_std). Он служит базовым фундаментом для обработки ввода.

Что делает этот код:
1. Через ассемблерные инструкции (модуль io) напрямую работает с портами процессора.
2. Проверяет статус PS/2 контроллера через порт 0x64 и ждет появления данных (методом опроса).
3. Считывает сырые скан-коды нажатых клавиш из порта 0x60.
4. Переводит полученные байты (скан-коды) в базовый набор клавиш: Q, T, O, Enter и Backspace.
